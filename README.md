Корневая директория проекта содержит набор тестов и файлы со вспомогательными инструментами:

- директория pages содержит файлы с классами для страниц;
- в директории tests лежат файлы с тестами, для каждой страницы — свой файл;
- в файлах директории locators определены локаторы, используемые в тестах;
- файл conftest содержит фикстуры, необходимые для запуска тестов;
- файл data хранит тестовые данные;
- директория allure_results содержит JSON-файлы с результатами выполнения тестов для генерации отчета;

Набор тестов:

1. Тесты в файле test_redirect проверяют переходы на главную страницу "Самрката" при клике на лого "Самоката" и на главную страницу «Дзена» при клике на лого "Яндекса";
2. Тесты в файле test_important_guestions проверяют соответствие содержания ответов на вопросы в разделе «Вопросы о важном» на главной странице "Самоката";
3. Тесты в файле test_create_order покрывают весь флоу позитивного сценария оформления заказа. В тесты через параметризацию передаются два набора пользовательских данных. Для начала оформления заказа использованы две разные точки входа.

Команда, запускающая все тесты: `pytest -v`.

Allure-отчет в формате веб-страницы генерируется командой `allure serve allure_results`.
